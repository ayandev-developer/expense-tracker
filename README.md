# Expense Tracker

An interactive Expense Tracker built using HTML, CSS, and JavaScript to manage expenses and calculate total spending.

## Features

* Add an expense name and amount
* Display recorded expenses
* Delete individual expenses
* Calculate total expenses dynamically

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Arrays and Objects
* Array Methods: forEach() and filter()

## What I Learned

* Managing structured data with arrays and objects
* Calculating totals using JavaScript
* Updating the user interface dynamically
* Filtering data to remove selected expenses
